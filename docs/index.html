GitHub Pages Theme

Jaace Theme

by @Jaace

A minimal dark/light theme for GitHub Pages. Pure HTML, CSS, and JS — no dependencies, no build step.

Usage

Add two lines to any HTML page:

In <head>
<link rel="stylesheet" href="https://jaace.github.io/theme/style.css">
Before </body>
<script src="https://jaace.github.io/theme/theme.js"></script>

What you get

  1. Dark/light mode with system preference detection and localStorage persistence
  2. Design tokens via CSS custom properties — override --accent to change the entire palette
  3. Pre-styled components: nav, hero, sections, code blocks, steps, callouts, footer
  4. Copy-to-clipboard buttons that just work

Starter template

Copy this to start a new GitHub Pages site with the theme:

<!DOCTYPE html> <html lang="en" data-theme="dark"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My Project</title> <link rel="stylesheet" href="https://jaace.github.io/theme/style.css"> </head> <body> <nav> <span class="nav-brand"><span>~</span>/my-project</span> <div class="nav-right"> <button class="theme-toggle" id="theme-toggle" aria-label="Toggle theme"> <!-- paste sun/moon SVGs from the theme repo --> </button> </div> </nav> <section class="hero"> <p class="eyebrow">Category</p> <h1>Project Name</h1> <p class="tagline">One-line description.</p> </section> <section> <h2>Section</h2> <p>Content goes here.</p> </section> <footer> <span class="footer-note">Built by @You</span> </footer> <script src="https://jaace.github.io/theme/theme.js"></script> </body> </html>
